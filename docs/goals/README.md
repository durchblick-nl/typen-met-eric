# Goals

Diese Dateien sind fertige Zieldefinitionen, die als Inhalt fuer Codex-Goals oder als normaler Auftrag kopiert werden koennen.

Empfohlene Nutzung:

```text
/goal
[Inhalt aus der passenden Goal-Datei einfuegen]
```

Falls die Codex-Oberflaeche kein benutzerdefiniertes `/goal` unterstuetzt, kann derselbe Inhalt einfach als normale Nachricht verwendet werden.
